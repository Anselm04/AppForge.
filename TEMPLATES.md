# AppForge Template Marketplace

Browse and deploy production-ready app templates.

## Quick Start

### 1. Browse Templates

```bash
npm run dev
# Navigate to /templates
```

### 2. Find Your Template

- Search by keyword
- Filter by category
- Filter by use case
- Preview live demo

### 3. Customize & Deploy

- Click "Use Template"
- Customize branding
- Configure features
- Deploy with one click
