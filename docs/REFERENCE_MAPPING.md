## Licence rules and provenance

- Reference repositories remain separate: no vendoring of the repositories, no source copying in this commit.
- Approved for future **file-by-file** review: MIT, Apache-2.0, or BSD variants with retained notices/attribution. Nested/proprietary directories and incompatible transitive material are excluded even inside otherwise permissive repositories.
- **AGPL, GPL, unclear, or NOASSERTION:** pattern study only, original independent code, no pasted code; this rule also applies to Plane, Macro, Twenty, and any reference that reports NOASSERTION.
- Original code is preferable where the implementation languages or service contracts differ. **`reimplement` does not mean copy-paste.**
- Preserve existing working AppForge code; repair only demonstrated faults and add regression tests before replacement.
