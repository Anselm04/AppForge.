# AppForge remaining engineering: source evidence and executable acceptance

**Date:** 2026-11-15 NZT. **Audit base:** `main` containing merged PRs #402, #403, #405, #406, #408 and #410. **Authority:** `docs/SOURCE_OF_TRUTH.md`; code and CI evidence supersede this document.

## Strict production and reference boundaries

Fly.io is disconnected following unacceptable charges. Do not connect Fly, create machines, run paid provider calls, charge cards, invoke live Stripe, or deploy AppForge publicly. GitHub Actions CI and local/mock-only execution are permitted. The existing customer-owned Vercel path is separate from AppForge's own always-on builder host. A mocked provider response is never proof of a live provider.

Reference repositories are **source inputs**, not automatic drop-in replacements. Keep the original AppForge identity, tenancy, billing, stack and job contracts. Review each source file's license and behavior before adapting. The installed Bolt.diy source (`Anselm04/Bolt-DIY-Source-Code-Reference/app/lib/runtime/message-parser.ts`, MIT) was compared and adapted in merged #410. Keycloak's `services/src/main/java/org/keycloak/authentication/authenticators/browser/OTPFormAuthenticator.java` (Apache-2.0) informed the owner-only TOTP challenge/verify repair in PR #411, which is not yet merged at this audit base. Medusa's root LICENSE is MIT **except Enterprise Edition files**, which must not be copied without rights. OpenHands is MIT; Coolify, Trigger.dev, Keycloak and Playwright have Apache-2.0 LICENSE files. Other reference code has not been exhaustively compared and cannot be represented as integrated or verified.

## What is already genuinely proven

- #402: stack-specific package manifests; #410: Bolt-style generated file-action parsing; #405: parsed generated source packaged with AppForge ZIP exporter, extracted, unit-tested, started over real local HTTP, edited and reopened with persistent data; #408: production owner-MFA fallback refusal; #403/#406: offline CI and fail-closed formatting/deployment URL guards. Each cited PR passed exact-head GitHub checks before merge.
- None of these separately proves one real authenticated customer completed a sanctioned Stripe test-mode checkout, invoked the real AppForge build pipeline, edited and saved a product, reopened it in the AppForge UI and deployed it to authorized customer-owned infrastructure.
- Do not label AppForge fully production-ready until that entire chain passes as one evidence-backed run, with matching artifact checksums and the final release SHA.

Correct each actual source defect and attach its reproducible regression test; do not replace working subsystems wholesale.
